演示账号：`3343625681`。登录时选择“管理员”，手动输入另行提供的演示密码，并勾选隐私与身份说明。首次登录后按页面选择学校。

验证：`node --experimental-strip-types qa/demo-auth.test.mjs`。设置临时环境变量 `LOCAL_DEMO_ADMIN_TEST_PASSWORD` 后，额外运行正确密码及停用账号的登录测试；未设置时这两项跳过。不要把密码写入受 Git 跟踪的环境文件。
