# 大学生日常心理与生活自评题库

共 **500 道原创中文题**，分为 **20 个主题，每主题 25 题**。面向成年大学生的日常自我了解与功能原型，回顾过去两周。

这是按校园日常场景编写的原创草案。已检索并核对 IPIP 与 WHO 官方参考资料，来源及复用说明见 [SOURCES.md](SOURCES.md)。题目没有经过心理测量学验证或心理专业人员逐条审核，不是专业筛查量表、官方译本或临床诊断工具。

## 作答方式

1. 先选择一个感兴趣的主题，一次展示该主题的 25 题；不要默认强制做完 500 题。
2. 统一提示：“回顾过去两周，在相关情境中，每条描述符合你实际经历的频率是多少？”
3. 单选：从不、很少、有时、经常、几乎总是；另设“不适用／没有遇到这种情境”和“暂不回答”。所有题都可跳过，可随时退出。
4. 没有遇到考试、住宿冲突、求助等特定情境时，选择不适用，不计为“从不”。
5. 完成后可展示个人回答及主题内的频率分布，邀请用户挑选一项想继续了解的事情。

## 结果解释

**不计算心理健康总分，不提供疾病结论、严重程度、常模百分位或诊断阈值。**

- `indicator=resource` 表示支持、习惯或应对方式；`challenge` 表示日常可能遇到的负担。
- 每组含 20 条资源描述和 5 条困难描述，交错排列便于阅读。这是内容组织方式，不是经过验证的量表结构。
- `order` 只是选项显示顺序，不是量表分数；不把两类题混加，不做反向计分。
- “暂不回答”和“不适用”独立展示，不能转成 0 分；若算作答分布，分母只包括选择五个频率选项的实际回答。
- 全部跳过时显示“本次没有可回顾的回答”，不要显示 0% 或评价状态。
- 不跨用户排名，不据此自动通知教师或管理员，也不自动触发转介、处分或所谓风险分级。
- 随机抽题、减少题数或改变选项，只能作为新的内容原型，不能宣称与任何正式量表等效。

展示建议：“这是一次日常自我回顾，没有标准答案，也不用于判断是否患有心理疾病。”如果困扰持续影响学习、睡眠或日常生活，可提示联系学校心理中心或合适的专业人员。

## 接入说明

题库位于仓库的独立 `Content` 目录，**本次没有添加 APP 页面、后端接口或数据库迁移，也没有上传个人作答**。现有网站或 APK 不会仅因加入这些文件就出现测评入口。

前端或后端可以读取 JSON 的 `themes` 生成主题列表，按 `question_ids` 显示题目，并使用 `response_options`、`skip_options` 构建单选项。每份回答应关联 `bank_id`、`version`、`question_id`，选项保存 `code`，不能依赖显示顺序或题干作为主键。

例：

```json
{
  "bank_id": "college-daily-self-reflection-zh-cn",
  "bank_version": "2026.10.15",
  "question_id": "CDSR-0001",
  "answer_code": "sometimes"
}
```

这是字段示意，不是可直接部署的接口或建表 SQL。

默认建议只在当前会话回顾答案。若以后保存结果，需另行实现明确同意、本人访问控制、保留与删除规则；后端从认证会话确定用户身份，不信任客户端提交的用户 ID。教师或管理员不因角色名称而自动获得所有学生的个人答案。具体存储方式应配合当前 Go 后端，不能直接向历史 `app.*` 表导入并假定线上已接入。

用户公开展示的应是题目和个人回顾，不应把“资源题／困难题”等内部标记当作评分标签。

## 验证

在本目录运行（Node.js 22+，无需安装依赖）：

```sh
node validate.mjs
node --test validate.test.mjs
```

检查 500 题总数、20 个主题、每组 25 题、唯一 ID 与题干、连续题号、选项、题目归属、来源引用、跳过规则，以及不生成诊断分数的配置。检查通过仅说明内容文件结构一致，不代表临床有效或已完成用户研究。

后续修改题意或选项时应更新版本；不要复用已有题目 ID 表示另一个概念。正式用于学生评估前应由具备相应专业能力的人员审阅，结合实际用途开展理解度与测量适用性评估。
