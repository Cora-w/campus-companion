# IPIP大五人格100题（中文试译版）

共 **100 题、5 个维度、每维度 20 题**。采用 IPIP 官方 Big-Five Factor Markers 页面中五个 **20-item scale** 段落，保留英文原题及正反向计分方向。与旁边的 500 题日常心理自评是两套独立材料。

中文为本项目逐题试译，**尚未经专业翻译审校、回译或中国大学生样本验证**，不宣称为官方中文版，也不继承原英文量表的信度和常模。适合当前的内容原型与自我探索，不用于心理疾病诊断、人格障碍筛查、录取招聘或学生排名。

## 文件

| 文件 | 用途 |
|---|---|
| question-bank.json | 100道中英文题、维度、选项、来源定位及计分键 |
| question-bank.md | 方便老师和开发人员逐题核对的阅读版 |
| scoring.mjs | 无依赖的纯函数，按完整维度计分，无网络与存储操作 |
| scoring.test.mjs | 题库、反向计分、漏答和非法输入的测试 |
| SOURCES.md | 官方来源、许可、翻译和验证边界 |

## 五个维度

| 维度 | 正向题 | 反向题 | 项目题号 |
|---|---:|---:|---|
| 外向性 | 10 | 10 | IPIP100-001—020 |
| 宜人性 | 14 | 6 | IPIP100-021—040 |
| 尽责性 | 11 | 9 | IPIP100-041—060 |
| 情绪稳定性 | 5 | 15 | IPIP100-061—080 |
| 智性／想象力 | 13 | 7 | IPIP100-081—100 |

第四维度越高代表按该键计算的情绪稳定倾向越高，不是神经质越高。第五维度保留官方 Intellect / Imagination 含义，不是智商或学习能力测验；不能把分数低解释为“不聪明”。五维特征没有统一的优劣顺序。

## 作答与展示

按“通常的自己”回答，不沿用500题库的“过去两周”。五级选项从“非常不符合”到“非常符合”，中间为“中间程度（既非符合也非不符合）”。可选“不适用／不理解题意”或“暂不回答”，允许退出。

阅读版按维度分组以便核对。JSON 的 `administration_order` 将五个维度轮流穿插，这是项目定义的呈现顺序，不是官方统一题号或经过单独验证的题序。实际页面不要显示每题的正反向标记，避免引导回答；支持分页和进度，不强制用户完成。

## 计分

依据官方键：正向 `value`，反向 `6 - value`。每维20题全部有效回答后，原始分是20题得分之和，范围20—100；均分为原始分除20，范围1—5。均分是本项目方便展示的算术转换，不是百分位。

跳过、缺失或 `null` 均不当作中间分、不补分、不按比例推算。某维不完整则该维 `raw_sum`、`mean` 为 `null`，其余完整维度可计算；这是本项目保守的缺失值处理策略，不声称是官方缺失规则。字符串数字、布尔值、小数、超范围值、未知题号会报错，调用方不得忽略错误后继续显示旧结果。

不输出综合人格总分、固定人格类型、MBTI字母、临床阈值或人群百分位；不把同一用户五维得分直接排序为“最强/最弱能力”。均分3只是回答量尺中点，不能标为人群平均值或正常分界。结果只作带明确限制的自我探索提示。

## 接入示例

```js
import { scorePersonality } from './scoring.mjs'
// bank 是读取 question-bank.json 后的对象。
const result = scorePersonality(bank, {
  'IPIP100-001': 4,
  'IPIP100-002': 'prefer_not_to_answer',
})
// 此示例未完成任何维度；各维分数为 null。
```

保存回答时应关联 `bank_id`、`bank_version` 和题号；由后端认证确定用户身份。默认不自动保存或分享答案，保存前另行取得明确同意，并实现本人访问、删除和保留规则。不要自动把人格答案或分数发送给教师、管理员、家长或用于风险预警。

本次仅提交内容与计分工具，**没有接入 APP 页面、API 或数据库**。数据文件中的隐私要求并非已实现的权限控制。

在本目录运行：

```sh
node --test scoring.test.mjs
```

正式面向学生发布前，应完成专业翻译审校、理解度评估及与实际用途相匹配的测量验证。修改题意或选项时需更新版本并重新评估；保留来源英文用于复核。
