# 16型人格偏好自评（原创100题）

本项目的人格题库改为 **E/I、S/N、T/F、J/P 四组偏好**，每组25题，共100题。完整作答且四组均不打平时，输出 INFP、ENTJ 等四字母**参考类型**，附原创类型标题、特点描述和一条反思建议。

参考的是MBTI公开的类型形式；**本题库不是官方MBTI测验**。100题、计分公式和16型说明均为本项目原创，未经过专业逐题审核、心理测量学验证或常模研究。结果不是诊断、人格优劣或固定身份，也不是从旧大五分数换算而来。

## 直接试答

下载本目录的 **preview.html**，双击用浏览器打开即可，无需安装依赖或启动服务器。每页10题，共10页，支持返回修改、跳过、提前查看进度结果和清空重做。移动端浏览器也可使用。

页面内嵌题库和计分代码，无网络请求、不用Cookie或本地存储、不发送作答；刷新会清空答案。外部来源链接仅在主动点击时打开。

仓库中的HTML源文件链接不能直接当成已部署网站。此页面是独立试答入口，**尚未接入现有APP导航、后端API或数据库**。

## 四组偏好

| 偏好组 | 本项目含义 |
|---|---|
| E / I | 更偏向通过外部互动，还是通过个人空间和内部整理进入状态 |
| S / N | 更关注具体事实与经验，还是整体联系与可能性 |
| T / F | 决策更先侧重逻辑和一致标准，还是价值、需要与人的处境 |
| J / P | 更倾向明确安排和收尾，还是保持选项与灵活调整 |

不是“外向好、内向坏”；T/F不代表有无感情或理性，J/P不代表责任心高低，S/N不代表想象力或智力优劣。每个人都可以使用各组的两侧。

## 原创计分规则

选项1—5：非常不符合、比较不符合、中间程度、比较符合、非常符合。跳过使用 `not_applicable`、`prefer_not_to_answer`，缺失或null同样不算作有效回答。

每题先减3，将符合程度居中至-2至2。指向本组左字母E/S/T/J的题按原值，指向右字母I/N/F/P的题乘-1，同组25题相加，范围-50至50。

- 大于0：选择本组左字母；小于0：选择右字母。
- 等于0：该组为 `tied`，不选字母，显示X及可能组合。
- 任一题漏答或跳过：该组为 `incomplete`，不计算分数或字母，不补分。其他完整组仍可显示倾向。
- 四组完整且均非零：产生四字母 `type` 和 `reference_type` 状态。
- 四组完整但有打平：`type=null`，状态 `ambiguous`；`candidate_types` 是已明确字母约束下的组合，不是概率。
- 任一组未完成：`type=null`，状态 `incomplete`；不推荐完整类型。
- 非零绝对值不大于5时显示“差距较小”的提示。这只是项目选择的界面提醒，未经统计验证，不能解释为置信度或诊断界限。

每组13题指向左侧、12题指向右侧。居中后全选中间选项仍严格为0，但这种结构及作答风格可能影响结果；没有经过常模校准。展示不使用“你有80%概率是INFP”“超过90%的人”等未经支持的说法。

## 开发调用

```js
import { scoreTypes } from './scoring.mjs'
// bank读取question-bank.json；答案以题号为键。
const result = scoreTypes(bank, { 'TYPE100-001': 4 })
// 未完成时 result.type === null，不显示完整类型。
// 完成且无打平后，从 type-profiles.json 的 profiles[result.type] 取解读。
```

必须使用本题库自己的 `bank_id`、版本和题号；旧IPIP答案不可迁移、重评分或直接换算为四字母类型。实际页面不显示逐题key，避免暗示某个答案更理想。16个原创标题不是官方昵称，也没有复制其他网站的专有类型报告。

默认只在本人当前会话回顾答案；后续若接入保存，需另外实现明确同意、本人权限、删除与保留策略。不能自动向老师、管理员或家长共享，也不能用于招生、招聘、处分、预警或能力排名。

## 验证与重新生成页面

```sh
node --test scoring.test.mjs
node build-preview.mjs
```

每次修改JSON或scoring.mjs后必须重新生成preview.html。旧大五材料保留于归档目录以便追溯，不再是当前类型问卷的接入入口。已有500道日常心理自评题保持独立。
